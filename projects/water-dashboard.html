MHS Water — ระบบเฝ้าระวังและติดตามสถานการณ์น้ำแบบเรียลไทม์ จังหวัดแม่ฮ่องสอน

เว็บแอปพลิเคชันติดตามปริมาณฝนและระดับน้ำแบบเรียลไทม์สำหรับจังหวัดแม่ฮ่องสอน ดึงข้อมูลสถานีตรวจวัดจาก ThaiWater API และภาพเรดาร์ฝนจาก RainViewer มาแสดงผลบนแผนที่เชิงโต้ตอบ พร้อมกราฟแนวโน้มย้อนหลังรายสถานี

โจทย์และที่มา

เจ้าหน้าที่ในพื้นที่จำเป็นต้องติดตามสถานการณ์น้ำอย่างต่อเนื่อง โดยเฉพาะในช่วงฤดูฝนที่มีความเสี่ยงต่อการเกิดอุทกภัย จึงพัฒนาเว็บแอปที่รวบรวมข้อมูลจากสถานีตรวจวัดของกรมทรัพยากรน้ำ (ผ่าน ThaiWater API) และภาพเรดาร์ฝนแบบเรียลไทม์ มาแสดงผลบนแผนที่เดียวกัน แบ่งเป็นสองโมดูลหลักคือ ติดตามปริมาณฝน และ ติดตามระดับน้ำ

วิธีการดำเนินงาน

  • ดึงข้อมูลสถานีตรวจวัดปริมาณฝน/ระดับน้ำแบบเรียลไทม์จาก ThaiWater API
  • ซ้อนภาพเรดาร์ฝนจาก RainViewer และภาพถ่ายดาวเทียม ESRI World Imagery เป็นชั้นข้อมูลอ้างอิง
  • จัดทำขอบเขตการปกครอง (อำเภอ/ตำบล/หมู่บ้าน) เป็น GeoJSON แสดงผลด้วย Leaflet
  • พัฒนากราฟแนวโน้มปริมาณฝนและระดับน้ำย้อนหลังรายสถานีด้วย Chart.js
